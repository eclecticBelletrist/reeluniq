This folder bundles other software. reeluniq itself is Apache-2.0 (LICENSE, NOTICE).

FFmpeg (ffmpeg, ffprobe), unmodified static builds. reeluniq starts them as separate programs and does the video work through them.
The builds include x264 and x265 and are licensed under the GNU GPL, version 3 (licenses/GPL-3.0.txt; the FFmpeg and x264/x265
copyright notices are in each build's own --version and --license output).

  Windows x64    BtbN FFmpeg-Builds, release autobuild-2026-10-26-14-25, ffmpeg-n8.1.3-24-g92611900bb-win64-gpl-8.1.zip
                 https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-10-26-14-25
                 build scripts and the exact source revisions: https://github.com/BtbN/FFmpeg-Builds (tag of that release)
  macOS arm64    Martin Riedl static build 9.0.2, https://ffmpeg.martin-riedl.de/download/macos/arm64/1789931890_9.0.2/
  macOS Intel    Martin Riedl static build 9.0.2, https://ffmpeg.martin-riedl.de/download/macos/amd64/1789931006_9.0.2/
                 build script and sources: https://git.martin-riedl.de/ffmpeg/build-script

The corresponding FFmpeg source code is available from https://ffmpeg.org/download.html (release 8.1.x and 9.0.x), and on request from
the reeluniq project page https://github.com/eclecticBelletrist/reeluniq for at least three years after the release.

Python packages inside the program, each under its own licence (copied into licenses/):
  NumPy (BSD-3-Clause), opencv-python-headless (Apache-2.0; its wheels bundle LGPL FFmpeg libraries), PyInstaller (GPL-2.0 with
  the bootloader exception, which allows use in non-GPL programs), and the Python runtime (PSF licence).
